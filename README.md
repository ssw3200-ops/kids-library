정보나루는 서버 IP를 등록하지 않으면 하루 500건까지만 돼요. GitHub Actions는 IP가 고정이 아니라서 등록할 수 없어요.
- 인기 목록: 매일 54건 (전국 + 17개 시·도 × 3개 연령)
- 소장 도서관: 남은 한도(약 420건)로 매일 나눠 채움 → 세종·대전 먼저, 전국은 약 6일이면 다 채워짐
- 같은 날 수동 실행분도 `docs/cache/usage.json`에 합산해서 한도를 넘지 않게 함

## 알아둘 점
- 정보나루의 "대출 가능"은 전날 기준이고 실제와 많이 달라서 쓰지 않음 → 소장 여부만 보여주고, 실제 대출 상태는 도서관 홈페이지 링크로 확인
